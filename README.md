# Yu_Launcher
WEB/PC ゲームアシスタントソフトウェア

## 更新時のデータ保護
- 更新前は、存在するWebView2・Games・htmlフォルダーと必須の`settings.toml`を退避し、全コピー成功後だけ親フォルダーの`Temp`として公開します。
- 次回起動時は、存在する退避項目から不足ファイルだけを復元します。保存先の既存ファイルは上書きせず、復元完了後に既知の退避項目を削除します。
- コピー失敗時の`Temp.pending.*`と、想定外の項目を含む`Temp`は保持します。既存の`Temp`があると更新を中止します。手動で整理する場合は、先にデータの復旧を確認してください。
