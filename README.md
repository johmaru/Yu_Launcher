# YuLauncher

[日本語](README.md) | [English](README.en.md)

PCゲーム、Webゲーム、Webサイトをまとめて管理するWindows用ランチャーです。

## 主な機能
- **PCゲーム・アプリの管理**：登録したアプリの起動、アイコン表示、ファイルが見つからない場合の状態表示。
- **Webゲーム・Webサイトの利用**：既定ブラウザーまたは内蔵ブラウザーで開く、専用ウィンドウでWebゲームをプレイ。
- **Webページの保存**：保存したページをローカルで表示。
- **登録項目の整理**：検索、ジャンル分類、項目ごとのメモとWikiデータの管理。
- **表示のカスタマイズ**：日本語・英語の切り替え、ウィンドウサイズ、フルスクリーン、メモの文字サイズ、区切り線の色の設定。

## 使い方
1. 一覧の「追加」を押し、追加画面のタブから種類を選びます。
2. 入力カードに名前とファイルまたはURLを設定し、右下の「作成」を押します。
3. 一覧から項目を選び、「起動」ボタンを押します。

名前検索とジャンルは同時に使えます。`Ctrl+F`で検索へ移動し、検索欄の`Esc`で検索語を解除します。一覧で項目を選んで`Enter`を押すか、ダブルクリックでも起動できます。起動・プロパティボタンは詳細本文をスクロールしても表示されます。

検索・ジャンル・選択は編集後も保持します。選択項目が絞り込み条件に合わなくなった場合は選択を解除します。検索結果がない場合は「絞り込みを解除」、読み込みに失敗した場合は「再読み込み」を使ってください。

## 設定
- **一般**：区切り線の色、データの移行、アプリ情報。色は「適用」で即時反映します。
- **表示と言語**：言語、ウィンドウサイズ、メモの文字サイズ。「変更を保存」で保存し、サイズは次に画面を開いたときに反映します。
- フルスクリーン設定は切り替え時に保存します。

インポートは現在のデータと設定を上書きします。
