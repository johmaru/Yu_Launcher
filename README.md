# YuLauncher

[日本語](README.md) | [English](README.en.md)

PCゲーム、Webゲーム、Webサイトをまとめて管理するWindows用ランチャーです。

## 主な機能
- **PCゲーム・アプリの管理**：登録したアプリの起動、アイコン表示、ファイルが見つからない場合の状態表示。
- **Webゲーム・Webサイトの利用**：既定ブラウザーまたは内蔵ブラウザーで開く、専用ウィンドウでWebゲームをプレイ。
- **Webページの保存**：保存したページをローカルで表示。
- **Webゲームのログイン履歴**：今日の記録状況と、日時・判定方法をゲーム別に確認。
- **登録項目の整理**：検索、ジャンル分類、項目ごとのメモとWikiデータの管理。
- **表示のカスタマイズ**：日本語・英語の切り替え、ウィンドウサイズ、フルスクリーン、メモの文字サイズ、区切り線の色の設定。

## 使い方
1. 一覧の「追加」を押し、追加画面のタブから種類を選びます。
2. 入力カードに名前とファイルまたはURLを設定し、右下の「作成」を押します。
3. 一覧から項目を選び、「起動」ボタンを押します。

名前検索とジャンルは同時に使えます。`Ctrl+F`で検索へ移動し、検索欄の`Esc`で検索語を解除します。一覧で項目を選んで`Enter`を押すか、ダブルクリックでも起動できます。起動・プロパティボタンは詳細本文をスクロールしても表示されます。

検索・ジャンル・選択は編集後も保持します。選択項目が絞り込み条件に合わなくなった場合は選択を解除します。検索結果がない場合は「絞り込みを解除」、読み込みに失敗した場合は「再読み込み」を使ってください。

プロパティは「基本情報」「起動設定」「関連設定」に分かれています。複数起動の候補は展開して選択でき、「変更を保存」は本文をスクロールしても常に表示されます。

### Webゲームのログイン履歴
Webゲーム一覧に今日の記録状況を表示し、選択したゲームの「ログイン履歴」から50件ずつ履歴を確認できます。「記録なし」は未ログインや認証失敗を意味しません。

プロパティの「ログイン履歴の設定」、またはゲーム窓の「アプリケーション」メニューから判定方法を変更します。
- **接続判定（推定）**：対象サイトへの接続成功を記録します。実際の認証成功は保証しません。
- **成功URL**：同じoriginとパスの前方一致で判定します。クエリ・fragmentは無視します。
- **表示要素**：プレビューでログイン後の表示を選びます。iframe内も選べますが、canvasの描画部品やShadow DOM内の要素は選べません。
- **JavaScriptイベント**：信頼するコードだけを実行してください。サンプルと`yuLogin.complete()`・`onEvent()`・`whenVisible()`・`whenUrl()`を利用できます。クリックやsubmit自体は認証成功を保証しません。
- **通信条件**：プレビュー全体で受信した応答のURL・HTTPメソッド・状態コードと、必要に応じてJSONの値で判定します。HTTP成功だけでは認証成功を保証しません。

プレビューの「判定をテスト」は履歴に記録しません。設定は次の独立したゲーム起動から適用し、再読み込み・子窓は同一起動として最大1件を記録します。判定エラー時に接続方式へ自動変更することはありません。

「通信・イベントを観測」で別窓の観測ビューアーを開き、通信またはDOMイベントを選んで「判定条件へ反映」します。JSONは通信を選んで「次のJSON応答を取得」を押し、プレビューで同じ操作を再実行してください。同じウィンドウ・URL・メソッド・状態コードの次の応答1件だけを取得し、新しい通信の本文を表示します。自動再送はしません。取得は1MiBまでで、表示した値を選ぶと条件にできます。DOMのdetailは取得を許可した後のイベントだけが対象です。本文には個人情報が含まれる場合があり、伏せ字は完全な除去を保証しません。反映だけでは保存されないため、プレビューでテストしてから保存してください。DOM条件は既存のJavaScriptに追加されるので、既存条件でも成功を検出します。HAR読み込み、バイナリ復号、ゲーム内部の独自emitterの取得は行いません。

`pageshow`や`load`などページ表示時のDOMイベントを反映した場合、「判定をテスト」の後にプレビューを再読み込みしてください。既に発生したイベントは再検出しません。これらのイベントは未ログインでも発生するため、ページ表示の記録であり認証成功の証明ではありません。旧版で生成・保存したコードは自動更新されないので、修正版の観測ビューアーから再反映してください。

## 設定
- **一般**：区切り線の色、データの移行、アプリ情報。色は「適用」で即時反映します。
- **表示と言語**：言語、ウィンドウサイズ、メモの文字サイズ。「変更を保存」で保存し、サイズは次に画面を開いたときに反映します。
- フルスクリーン設定は切り替え時に保存します。

インポートは現在のデータと設定を上書きします。
